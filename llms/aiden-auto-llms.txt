# AiDEN Auto

> AiDEN Auto (Aiden Automotive Inc.) is a connected-vehicle software company whose
> software-only platform runs natively on Android Automotive OS (AAOS) infotainment head
> units, letting automakers, fleets and third-party service providers deliver in-cab
> mobility services — tolling, parking, fueling and charging, payments, insurance,
> roadside assistance, maintenance and regulatory compliance — without a phone, a
> downloaded app, or a bespoke per-OEM integration.

Generated by API Evangelist from the public apis.yml profile and live probes of

## API surface

**No public API surface.** As of 2026-09-14 AiDEN Auto publishes no developer portal, API
reference, OpenAPI/AsyncAPI/GraphQL contract, SDK, MCP server or agent card.

- No docs, developer or api subdomain exists (docs.aidenauto.com,
  developer.aidenauto.com, api.aidenauto.com all fail DNS resolution)
- /developers, /docs, /api, /developer, /portal on aidenauto.com all return 404
- /openapi.json, /openapi.yaml, /swagger.json, /api-docs all return 404
- Every /.well-known/ path probed returns 404 on both aidenauto.com and www.aidenauto.com
- No first-party packages on npm, PyPI, or a public GitHub organization

The company markets "AiDEN APIs" and an "AiDEN Portal" as part of a partner-onboarding
process on https://aidenauto.com/partners ("Define workflow moments, required APIs,
architecture planning"; "integrate with AiDEN APIs"), but the only route to them is a
"Request A Demo" form. The contract sits behind a sales gate.

DISAMBIGUATION: aiden.eu / aidencloud.eu ("Aiden API Management developer portal",
Aiden WMS/POS/SAP Business One integration, Netherlands) and docs.stackgen.com/aiden
(StackGen's "Aiden" product) are DIFFERENT companies that share the name. Their specs and
developer portals are not AiDEN Auto's and must not be attributed to it.

## Products

- AiDEN in-vehicle platform for Android Automotive OS — one APK, OEM-branded, OTA-updated
- AiDEN Services Hub — the partner catalog of in-cab services
- AiDEN Portal — where service providers select vehicle signals and define activation
  triggers, without proprietary OEM APIs
- SENT-GEO — software-first Poland SENT cross-border freight compliance, delivered in-cab
  (built with Volvo Trucks CampX)

## Vehicle data and consent

Real-time vehicle signals (fuel level, tire pressure, battery state, engine data,
location) are brokered to partner backends under an application-level, GDPR/CCPA-aligned
consent model. The company holds three patents covering in-vehicle consent, payments and
data sharing (announced July 2026).

## Named partners and customers

Volvo Trucks CampX, HERE Technologies, IF Insurance, MAVI, Treads, HAAS.
